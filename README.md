# Python Projects: Beginner to Advanced

A collection of Python projects built while learning and improving my programming skills. The repository progresses from basic Python programming to intermediate applications and advanced projects involving APIs, databases, data analysis, automation, and AI/ML.

## About This Repository

This repository documents my Python learning journey through practical projects.

The projects are organized into three levels:

* **Beginner:** Python fundamentals, conditionals, loops, functions, strings, lists, dictionaries, and basic problem solving.
* **Intermediate:** Object-oriented programming, file handling, APIs, automation, databases, web scraping, and larger applications.
* **Advanced:** Data analysis, machine learning, computer vision, AI, backend development, and complex applications.
